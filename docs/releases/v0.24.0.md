# v0.24.0 — 子 Agent 编排系统 + 记忆重构

## Agent 编排系统（orchestrator 重写）

- **Agent 类型分化** — `general`（全工具）/ `explore`（只读探索）/ `plan`（架构设计）/ `verify`（代码审查）
- **按类型裁剪工具** — explore/plan/verify 只读 agent 拿不到写工具，权限边界明确
- **结构化输出** — JSON Schema 校验 + 失败自动修正重试
- **Token 预算** — 超预算自动截断，防止子任务撑爆上下文
- **Pipeline 编排** — 串行多阶段，每阶段结果传入下一阶段
- **对抗性验证** — 多 voter 从不同角度尝试反驳结论，多数表决
- 实时流式输出 — 子任务进度/结果开窗展示到主对话

## 记忆系统重构

- **双层文件存储** — 项目级 `.stardust/memory/` + 全局用户级 `~/.stardust/memory/`
- 对齐 Claude Code 风格，记忆直读文件（`MEMORY.md`）
- 去掉旧的自动提取 / 分层 / Supabase 依赖

## 工具精简

- 移除 git / github / ide 前端工具（GitHub 集成移除）
- 工具统一为 `workspace_` 前缀，减少冗余
- Rust sidecar：移除 git handler，重构 mcp 处理

## 其他

- 聊天事件类型精简，移除已删工具的注册逻辑
- `.stardust/` 本地配置（命令白名单）不入库
